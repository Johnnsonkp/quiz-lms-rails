# Image Assets for QLearn.ai

You need to add the following image files to this directory (`app/assets/images/`) for complete SEO and social media optimization:

## Required Images:

### Favicon Set
- **favicon-16x16.png** (16x16 pixels)
- **favicon-32x32.png** (32x32 pixels)
- **apple-touch-icon.png** (180x180 pixels)

### Social Media Share Image
- **qlearn-social-share.png** (1200x630 pixels)
  - This will be used for Facebook, Twitter, LinkedIn, and other social media platforms
  - Should showcase your app's interface, features, or value proposition
  - Include your logo and some compelling text

### Web App Manifest Icons
- Update your existing **quiz-icon.png** to be 192x192 pixels for PWA support

## Design Recommendations:

### Social Share Image (1200x630px)
- Background: Clean, modern design with your brand colors
- Include: QLearn.ai logo, tagline "AI-Powered Learning Platform", and key features
- Show: Dashboard screenshot or quiz interface
- Colors: Use your theme color #3B82F6 (blue) as accent
- Text: High contrast, readable fonts
- Elements: Study analytics charts, quiz cards, or progress tracking visuals

### Favicon Set
- Should be simplified version of your main logo
- High contrast for small sizes
- Clear and recognizable at tiny sizes

## Tools to Create Images:
- **Canva** (templates available for social media images)
- **Figma** (for custom designs)
- **Favicon.io** (for generating favicon sets)
- **RealFaviconGenerator.net** (comprehensive favicon generator)
